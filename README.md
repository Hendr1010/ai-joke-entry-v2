# Make the AI judge laugh — v2

Entry for the make.fun competition [ai-joke-03](https://make.fun/bounty/ai-joke-03)
("Make the AI judge laugh", $150 prize pool, top 50 paid).

The program `main.ts` (Node 22, standard library only) writes one joke about
AI coding agents to `/output/entry.txt`:

> My coding agent is so confident, it deploys on Fridays.

The joke plays on the developer taboo of Friday deploys: the agent ships
confidently without understanding the risk. Deterministic — two runs write
the same bytes.
